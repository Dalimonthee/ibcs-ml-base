How it Works

Upload a dashboard image for IBCS analysis. ML models add visual overlays for chart detection, OCR labels, and bar geometry. Optionally enable live LLM analysis with your own OpenAI API key for full rule checks on any file.

  1. Compliance report (optional) Turn on Run live LLM compliance analysis and enter your OpenAI API key to generate rule checks, violations, and explanations for any upload. Without LLM, pre-generated reports from ibcs_compliance_report_openai.json are matched by filename.
  2. Chart detection Roboflow draws bounding boxes around horizontal and vertical bar charts on your dashboard.
  3. Labels & bars OCR and bar detection produce overlay images so you can inspect detected labels and bar regions visually.

ML overlays are always generated live. Compliance scoring comes from the LLM (if enabled) or a matching bundled report.
